# OpenMES

MES（製造実行システム / Manufacturing Execution System）という業務的に複雑なドメインにおいて、
**Database per Service（サービスごとのDB分離）が成立するか**を検証するための実験プロジェクトです。

検証を通り抜けた範囲に限って、動作するミニマムな MES ソフトウェアを構築することをゴールとします。

## 何を検証するのか

MES はマスタ・生産指示・実績・在庫が密結合しやすく、
「マイクロサービス化しようとすると結局1つの巨大DBに戻る」と言われがちな領域です。

本プロジェクトでは以下を検証します。

> 生産指示 / 実績収集 / 在庫・ロットトレース を独立したデータストア境界に分割し、
> サービス間はAPIのみで連携する構成が、実装量・整合性・性能の面で成立するか。

分離の実現方式は **単一 Postgres インスタンス上の「スキーマ + 専用ロール」による論理分離**とします。
「規約として分けている」のではなく、**DBの権限機構が越境を物理的に拒否する**状態を作ることで、
分割が本当に成立しているかを検証可能にします。

詳細は [docs/01-verification-plan.md](docs/01-verification-plan.md) を参照してください。
