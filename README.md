# OpenMES

MES（製造実行システム / Manufacturing Execution System）という業務的に複雑なドメインで、
**マイクロサービス化、特に DB リソースの分割が成立するか**を検証し、
検証を通った範囲でミニマムな MES を構築する実験プロジェクトです。

## 2つの目的

1. **技術検証** — MES のように業務が密結合しやすい領域で、
   サービスごとにデータストアを分割する構成が成立するかを、実際に作って確かめる
2. **スキル向上** — 実装を通して、マイクロサービスの設計判断を
   自分で下せるようになること。**こちらが本命**

そのため、このプロジェクトは意図的にゆっくり進みます。
Claude は設計を先回りして確定させず、判断のたびに選択肢とトレードオフを提示します。
進め方の詳細は [ADR-0004](docs/adr/0004-collaboration-mode.md) と `CLAUDE.md` を参照。
